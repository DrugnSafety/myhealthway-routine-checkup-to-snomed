## 핵심 학습 포인트

1. **A시트 vs B시트 분리** — 같은 BMI 26.7이라도 A시트에서는 "Overweight present"로 1행, B시트에서는 "Overweight present + Obesity absent" 2행으로 등장. A는 측정사실, B는 임상판정.
2. **상위진단 확정 시 하위 생략** — 고혈압이 confirmed이면 prehypertension 행은 B시트에 만들지 않는다. 단 A시트에는 "혈압 — 고혈압 수치(24184005)"가 등장한다.
3. **always-generate 정책** — 검사가 시행되지 않아도 13개 핵심 항목은 not_measured로 행 생성. 이는 데이터 분석 시 "미측정 vs 정상"을 명확히 구분하기 위함.
4. **C시트의 ★ 마커** — `item_name_kr`에 ★YYYY를 붙여 어느 검진이 다른지 표기. 음성→양성 또는 양성→음성 변화 모두 추적.
5. **D시트의 ⚠ 표기** — 새 코드를 도입할 때마다 검증 상태를 함께 기록하여, 후속 세션에서 MCP 재검증할 항목을 추적.
